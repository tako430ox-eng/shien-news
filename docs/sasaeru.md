## 1. なぜ作るか

届け方の調査（`/mnt/project-files/reports/outreach/01_多くの人に届ける戦略.md`）は、検索から来やすいのは困っている本人より、家族・友人など余力のある「支える人」だと見立てた【推論】。狙う言葉は「生活保護」のような競争の激しい一般語ではなく、「親 家賃 払えない」のような具体的な場面の言葉。1ページ＝1つの場面と、その場で言う文・次の一歩、とした（同報告 段階2-3）。

## 2. 選んだ場面と理由

| ページ | 想定する検索 | 選んだ理由 |
|---|---|---|
| 入口 `/sasaeru/` | 家族 生活 困っている 支える | 場面の一覧と、どの場面でも役立つ3つのこと |
| `oya-yachin/` 親が「家賃が払えない」と言ってきた | 親 家賃 払えない／年金 家賃 足りない 親 | 既存の家賃編に一番近い。高齢の親は地域包括支援センターという別の相談先があり、家賃編だけでは案内しきれない |
| `shitsugyo-yachin/` 仕事を失い家賃が払えない | 子ども 失業 家賃／住居確保給付金 家族 | 住居確保給付金の「別居の家族の収入は含めない」は、支える人が最初に気にする点で、公式FAQで確かめられた |
| `taikyo/` 出ていくように言われた | 退去 言われた 家族／追い出し 保証会社 | 緊急度が高い。家賃編にある確認済みの案内（サインしない・記録・法テラス・追い出し条項）を、支える人向けに組み直せる |
| `denwa/` 代わりに・隣で電話する | 役所 電話 代わりに 家族／何て言う | このサイトの独自性（その場で読める文）が最も出る場面 |
| `seikatsuhogo/` 家族に生活保護をすすめたい | 生活保護 家族に連絡／扶養照会 | 「親族に知られたくない」は申請をためらう大きな理由。国の事務連絡（2021年）で確かめられる |

**見送った場面**（第2版の候補）：「お金を貸してと言われた」（貸付・借金の整理に話が広がり、確かめる資料が多い）、「死にたいと言われた」（心の相談は専門の公的ページ〈ゲートキーパーの手引きなど〉に任せる方が安全。今は各ページの上で相談窓口に案内するだけ）、「緊急連絡先として家賃を請求された」（法律の判断が入るため、法律の資料で確かめてから）。

検索結果の競合：今回の検索は米国向けの検索機能でしか試せず、日本の Google の順位は確かめていない。試した範囲では、家族向けの場面の検索には金融・生活情報サイトの記事が多く、「窓口で何と言うか」まで書いたものは目立たなかった【推論。件数も少ない】。公開後に Search Console の「検索で表示された言葉」で確かめる。

## 3. 案内と根拠の対応表（2026-11-16 確認）

【確認】＝公式資料にそう書いてある。【推論】＝資料から当サイトが判断したこと。ページの中でも、推論は「〜と考えられます」「当サイトの判断です」「場合があります」と書き分けている。

| 案内 | 区分 | 根拠（原文の要点） |
|---|---|---|
| 自立相談支援機関は、家賃が払えない等の困りごとを聞き、本人と支援プランを作る | 確認 | 厚労省「生活困窮者自立支援制度」：「あなただけの支援プランを作ります」、例に「家賃を払えない」 |
| 家族や周りの人からの相談も受け付けると書いている自治体がある（例：横浜市・東大阪市・中央区） | 確認 | 横浜市「ご家族や周りの方からのご相談も可能です」、東大阪市「ご家族や地域の方からのご相談も受け付けています」、中央区「ご家族など、周りの方からのご相談もお受けしています」。**国のページには記載なし。全国共通とは書いていない** |
| 相談は無料と書いている自治体もある | 確認 | 東大阪市「費用は無料です」、中央区「相談は無料です」。国のページには記載なし |
| 本人の了解がないと窓口が詳しく話せない場合がある／申し込みは本人の手続きが必要なことが多い | **推論** | 公式資料で直接は確かめていない。個人情報の一般的な扱いからの判断。断定せず「場合があります」「多く」と書いた |
| 地域包括支援センター：市町村が設置。高齢者や家族介護者の総合相談 | 確認 | 厚労省「地域包括支援センターについて」：「地域の高齢者や家族介護者に対して…相談支援を行い」 |

## 4. まだできていないこと・判断が要ること

- 専門家（社会福祉士・弁護士など）の確認は受けていない。
- 自治体ごとの違い（相談の受け方、転居費用の求職活動要件など）は全国分を照合していない。ページでは「窓口で確かめて」としている。
- 出典ページの変化の見張り（config/watch.json）に、今回使った主な資料のうち、まだ登録されていなかった2件（生活保護を申請したい方へ、扶養照会の事務連絡）を足した（2026-11-17）。
- トップの相談先の欄と家賃編の「隣で支える人へ」に、このページへのリンクを足した。
