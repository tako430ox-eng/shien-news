## 見送ったもの・状況が変わっていたもの

- **Actions の権限の分割・SHA 固定（項目10）**：取得する外部ページは自前の Python で文字として読むだけで、実行はしない。取得と保存を別の仕事に分けると、仕事の間でデータを渡す必要があり、11/25 にその受け渡し（artifact）で公開が4回失敗している。使っている Action はすべて GitHub 自身の actions/*。効果に比べて壊れる危険が大きいので今回は見送り。固定するなら、更新を知らせる仕組み（Dependabot など）と一緒に入れる。
- **出典の監視（項目10）**：レビュー後に入った PR #31 で、表示名が同じでリンク先だけ変わる変化も検知するようになっている（tests の test_body_link_destination_change_is_detected_with_same_label）。資料の中身（PDF・Excel）の監視は今回は入れていない。
- **各カードに「自動」を付ける（項目9）**：カードごとに付けると表示が重くなるので、新着の欄の説明に1回書いた。
