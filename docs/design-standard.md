## 1. 何を「プロのやり方」とするか

実務の公的サービスの設計者が使っている、公開された基準を土台にする。好みや思いつきで見た目を決めず、**基準の出典 → 決まり → 自動で測る → 前後を見比べる → 本人が判断**の順で進める。

| 出典（実際に読んだもの） | 取り入れたこと | 確認日 |
|---|---|---|
| デジタル庁デザインシステム「タイポグラフィ」 https://design.digital.go.jp/dads/foundations/typography/ （2026年8月5日更新） | 本文は16px以上（14px未満は原則使わない）。本文の行間は1.5倍以上で、定義値は 17px/170% など。見出しは太字で行間150%。字間は16〜26pxで2%。日本語にイタリックを使わない。リンクは下線 | 2026-11-19 |

## 2. 決まり（合否で確かめる）

### 文字

| # | 決まり | 理由（出典） |
|---|---|---|
| T1 | 文字の大きさは段だけ：14（札）・16（補足）・17（本文）・18（リード・h3）・22（h2）・28（h1）。641px 以上の画面では h3 20・h2 26・h1 36。`clamp()` などで中間の値を作らない | GOV.UK の段の考え方、デジタル庁の Std-17N-170 ほか |
| T2 | 14px 未満を使わない。補足でも 16px | デジタル庁 |
| T3 | 本文の行間 1.7、見出し 1.5。字間 0.02em | デジタル庁 Std-17N-170、Std-xxB-150 |
| T4 | 丸ゴシック（Zen Maru Gothic）は看板の名前と大見出し（h1）だけ。h2・h3・本文は同じゴシック体（太字 700 と標準 400 の2つ） | 書体を混ぜるほど、見出しと本文の質感がばらつく（当サイトの判断）。デジタル庁も見出しは本文と同じ書体の太字 |
| T5 | 見出し・選択肢・ボタン・短い説明は `word-break: auto-phrase` で文節改行。段落は `text-wrap: pretty`。`line-break: strict` で行頭の小さい「ゃ」などを避ける | Chrome の国際化機能。「切り替え／る」のような改行は素人っぽく見える最大の原因の一つだった |
| T6 | 太字は1段落に1か所まで。強調を重ねると、どれも強調でなくなる | 当サイトの判断（GOV.UK の該当文書は今回確認できず） |

### 形と余白

| # | 決まり |
|---|---|
| S1 | 角の丸みは 4px（小さな札）・8px（ボタン・入力欄・選択肢・入口の行）・12px（カード・囲み）・円だけ。999px（丸い札の形）は、折り返さない短い札（分野ボタン、電話番号ボタン）だけ |
| S2 | 余白は 8 の倍数を基本（8・16・24・32・48・64）。4・12 は部品の内側だけ |
| S3 | カードに影を付けない（1px の枠だけ）。家賃編の緊急タイルの太い枠と影は、押せる場所を目立たせる例外として残す（v1.2 でコタローさんが選んだ形） |
| S4 | 看板（緑の帯）は画面の端から端まで。中身の幅は本文と同じ 44rem まで |

### 部品

| # | 部品 | 決まり |
|---|---|---|
| C1 | 選択肢（ラジオ） | 縦に並べ、左に丸。選んだら丸が太い輪になり、枠と面の色も変わる（色だけに頼らない。強制カラーモードでも輪の太さで分かる）。横並びは「2つで短い」ときだけ。最初から選ばない。「分からない」を入れる |
| C2 | 緊急の案内（.notice） | 赤で全体を塗らない。白い面に左の太い赤線。中は「見出し（.notice-h）＋短い文か箇条」。電話番号のリンクは太字 |
| C3 | 次のページへの入口（.links .tool、場面の一覧） | 1行ずつ枠で囲み、右に「›」。行のどこを押しても進める。説明は2行程度まで |
| C4 | ボタン | 主（緑の塗り）と副（枠）の2種類。高さ 48px、角 8px。1つの画面に主ボタンは1つを目安 |
| C5 | 札（タグ・種類） | 角 4px、14px。押せない札は押せるもの（分野ボタン）と形を変える |

### 文章（ページを作るとき）

| # | 決まり |
|---|---|
| W1 | 大事な言葉を先に。1文に1つのこと。見出しは「何のための段か」が分かる言葉 |
| W2 | リンクの文字だけで行き先が分かるようにする（「こちら」にしない） |
| W3 | 「緑のボタン」「右の」のように色や位置で指示しない |
| W4 | 不安をあおる言い方、責める言い方をしない。できること・選べることを先に書く（トラウマインフォームド） |
| W5 | 公式資料で確かめたことだけを書き、出典と確認日を付ける（既存の決まりのまま） |

### アクセシビリティ（既存の決まりを引き継ぐ）

- 文字 4.5:1、部品の枠 3:1（`/mnt/project-files/design-system/check-contrast.js`）。
- 押せる部品 44px 以上（主な部品は 48px）。文中のリンクは除く。
- 暗い画面設定・印刷・強制カラーモード・動きを減らす設定で崩れない。
- 画面に固定する部品は、ほかの部品に重ねない。

## 3. 工程（新しいページ・直し・見直しのたびに）

1. **誰が・何をしに来るかを書く**：1〜2文で。困って来た人か、支える人か。スマホで、急いでいるか。
2. **中身の順番を決める**：緊急の案内 → 今日やること → 詳しい手順 → 窓口で言える文 → 出典。既存のページ（/shitsugyo/、/sasaeru/）の型を使う。
3. **既存の部品で組む**：`assets/site.css` の部品（.notice、.choose、.links .tool、.say、.today、.btn、.cta）だけを使う。足りないときは、この文書の決まりに合う部品を足し、この文書の「部品」の表にも書く。ページごとに独自の見た目を作らない。
4. **自動で測る**：
   ```
   python scripts/build.py --out site
   node scripts/design_audit.cjs site
   ```
   文字の大きさ・角の丸み・押せる大きさ・文節改行・はみ出しを測る。✗ が出たら直す。「最後の行が2字以下」は参考値（0 に近づける）。
5. **目で見比べる**：スマホ幅（390px と 320px）と PC 幅（1280px）で、変更前と変更後を撮って並べる。暗い画面設定も1枚。
6. **この文書の決まりで自己点検**：表の項目ごとに、合っているか、合っていないなら理由を PR に書く。
7. **PR にする**：前後の画像（または比較ページ）、`design_audit.cjs` の結果、テストの結果を付ける。公開ページの変更は、コタローさんの了承を取ってからマージする。

## 4. v1.2 → v2.0 で直したこと（2026-11-19 の点検結果）

点検は `scripts/design_audit.cjs` と、全7ページのスマホ・PC 幅の撮影で行った。

| 見つかった問題 | 基準 | v2.0 の直し |
|---|---|---|
| 文字の大きさがページごとに9〜14種類。28.08px・24.96px・19.89px のような段から外れた値（`clamp()` の途中の値） | T1 | 決まった段だけに。各ページ8〜11種類に減った |
| 13px・15px の小さい文字 | T2 | 14px（札）と 16px（補足）に |
| 見出しが単語の途中で折り返す（「切り替え／る」）。新しく作ったページ（/shitsugyo/、/sasaeru/、トップ）だけ文節改行が入っていなかった | T5 | 全ページの見出し・選択肢・ボタンに文節改行。最後の行が2字以下の段落は、トップ 7→1、/shitsugyo/ 5→0、家賃編 17→7、/sasaeru/ 2→0 |
| 丸ゴシックの極太（900）が h2・h3 にも使われ、ゴシックの本文と質感が合わない | T4 | 丸ゴシックは看板の名前と h1 だけ |
| 長い選択肢が丸い札の中で2〜3行に折り返し、形が崩れる。選んだ札は緑一色で、何を選んだか分かりにくい | C1 | 縦に並ぶラジオの行に。丸を左に出す |
| 緊急の案内が、赤い枠と赤い面の中に長い文が続く「壁」になっていた | C2・W1 | 白い面と左の赤線。見出し＋短い箇条に分けた（文の中身は変えていない） |
| 看板の約束が、丸い札の中で折り返して「ます」「せん」だけの行ができていた | S1・T5 | 札をやめ、✓ の付いた短い行に |
| トップの入口が、文字の長い緑の丸ボタン。支える人への場面一覧は、下線のリンクを白いカードで囲んだだけで、押せる範囲が分かりにくい | C3 | 枠と「›」の付いた入口の行にそろえた。行全体が押せる |
| 角の丸みが 999・16・12・10px と混在、影のあるカードとないカードが混在 | S1・S3 | 4・8・12px に整理。カードの影をやめた |
| PC 幅で看板が真ん中に浮いた箱に見える | S4 | 看板を画面の端から端まで |

**変えていないこと**：色（緑・黄・赤の意味）、看板の名前とロゴ、黄色い道、家賃編の緊急タイルの太い枠（コタローさんが v1.2 で選んだ「道しるべ（大胆）」の骨格）。文章の中身（制度の説明・出典）は変えていない。

## 5. 残っている課題

- **家賃編の最初の画面**：2026-11-19 の第2弾で、390×664・375×667・360×640 の画面では4つのタイルが「すぐ閉じる」の帯より上に収まった（文字は縮めず、間隔・タイルの高さ・説明文で詰めた）。幅320px と、文字を大きくする設定では、まだ収まらない。
- **文章の密度**：2026-11-19 の第2弾で /shitsugyo/ の 1〜4 節を書き直した（太字 23→10、1項目の平均 105→52字。docs/shitsugyo.md の 6）。5節と、ほかのページ（家賃編・支える人へ）の本文はまだ。書き直すときは、同じように変える前後の表と出典の照合を残す。
- **新着の見出し**：国の公式ページの見出しをそのまま載せる方針のため、長く読みにくい見出しも直せない（方針どおり）。
- **利用者による確かめ**：今回の判断は基準と計測に基づくもので、実際に困っている人が使って確かめたものではない。アンケートの回答が集まったら、この文書の決まりを見直す。
