# 運用の手引き

## 毎週すること（10〜20分の見込み。実際の量は動かしてから測る）

1. GitHub の Issues を見る。
   - 「出典ページに変化がありました」：書かれたページを開き、行動支援の試作の文面（金額・条件・窓口名・電話番号）が今も正しいか確かめる。直したら試作と設計書の確認日を更新し、Issue を閉じる。
   - 「情報源から新着が取れていません」：下の「壊れたとき」を見る。
2. サイトを開き、明らかに関係のないものが並んでいないか、大事なものが「除外」されていないかを見る。気づいたら config/rules.json の言葉を足し引きする（下の「分類を直す」）。

## やさしい説明を足す（任意）

大事なお知らせに、人が書いた短い説明を付けられます。GitHub の画面で data/notes.json を開き、鉛筆のボタンで編集します。

```json
{"url": "公式ページのURL（サイトのリンクと同じもの）",
 "text": "2文以内。誰が・何が・いつから。わからないことは書かない。",
 "checked": "2026-11-20",
 "reviewed_by": "確かめた人の呼び名"}
```

- 公式ページを自分で読んでから書く。AIに下書きさせた場合も、公式ページと照らして一文ずつ確かめる。
- 「受給できます」「申請代行」のような言葉は使わない（共通デザインの決まり 9）。

## 締め切りを足す（任意）

data/deadlines.json に、公式ページで確かめた期限だけを書きます。期限を過ぎると自動で消えます。

```json
{"title": "制度の名前と手続き", "who": "対象の人", "deadline": "2026-12-28",
 "url": "公式ページ", "source_name": "厚生労働省", "checked": "2026-11-20"}
```

## 分類を直す

config/rules.json の topics（分野）と kinds（種類）の keywords に言葉を足し引きします。exclude_keywords にある言葉が見出しにあると、サイトに出しません。直したら tests/test_pipeline.py の TestClassify に例を1つ足し、テストを通します。

## 壊れたとき

- **ある情報源だけ取れない**：公式サイトの作りや住所が変わった可能性が高い。ブラウザでそのページを開き、config/sources.json の url と item_href（記事のリンクの形）を合わせる。新しいページを保存して tests/fixtures に置き、テストを足す。
- **全部取れない**：GitHub Actions が止まっている可能性。Actions タブで失敗の記録を見る。
- **定期実行が止まった**：GitHub は、公開リポジトリで60日間動きがないと定期実行を止める（公式の説明）。このサイトはほぼ毎日データを保存するので普通は止まらない見込みだが、止まったら Actions タブから再開する。
- サイトは、最後に実際に取れてから72時間たつと、画面の上に「更新されていません」と出す。

## 情報源を増やすとき

1. その機関の「利用規約」「著作権」「RSS」のページを読み、再配布を断っていないか、公共データ利用規約（第1.0版）など出典を書けば使える条件かを確かめる。
2. config/sources.json に足し、license・license_url・credit・checked を必ず書く。
3. 見本のページを tests/fixtures に置き、テストを足す。

## やめるとき・引き継ぐとき

- 更新を止めるなら、サイトのトップに「更新を終了しました」と出し、古い情報が新しく見えないようにする（Pages を止める、または config/site.json の tagline を変えて build）。
- 引き継ぐなら、リポジトリの所有者を移すだけで動く（秘密の鍵や有料の契約はない）。

## 行動支援の試作（/yachin/）と運営者ページ（/unei.html）

- 置き場所：`pages/`。build.py が最後に `site/` へそのまま写す（生成したページと同じ名前のファイルは写さない）。
- **`pages/unei.html` に「【未記入」が残っている間は、`pages/` を一切公開しない。** 活動名と専用メールアドレスを書き込むと、次の自動実行で公開される。
- 試作の正本は `/mnt/project-files/action-support/app/index.html`（デザインのスレッドが更新）。公開版は直接直さず、`python scripts/publish_app.py <正本>` で作り直す。Google Fonts の読み込みを外し、`assets/fonts.css`（自前のフォントの部分集合）に替える。
- ページを開いただけで外のサーバーに接続するものを入れない（テスト `TestPages` が確かめる）。
