# 出典の変化の確認記録

`watch.yml`（毎週月曜 8:23 JST）が作る「出典ページに変化がありました」の Issue を、公式ページで確かめた記録です。新しいものを上に足します。

書くこと：Issue の番号、確かめた日、読んだ公式ページ、サイトの記述と照らした結果（一致／ずれ）、したこと（直した・確認日だけ更新・見張りの対象を変えた）。確認できた事実と推論は分けて書きます。
